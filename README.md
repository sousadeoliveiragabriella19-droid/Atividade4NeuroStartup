# Atividade4NeuroStartup
Aluno:Gabriella Sousa de Oliveira RA:2869704 Turma:BCC

O projeto a seguir se refere a uma loja online que classifica fotos de produtos. A lja realiza essa classificação a mão, por esse motivo Criamos um modelo que olha a foto de uma peça e diz a categoria (entre 10: camiseta, calça, pulôver, vestido, casaco, sandália, camisa, tênis, bolsa e bota), para reduzir o trabalho manual.
